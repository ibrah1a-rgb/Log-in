# حضور ومبيعات — تطبيق آيفون تجريبي

تطبيق لموظفي المحل مع حساب مدير ينشئ أسماء المستخدمين وكلمات المرور، وحضور وانصراف، وتسجيل المنتج والكمية وإجمالي البيع. يدعم الدخول السريع بـFace ID أو Touch ID بعد أول دخول بكلمة المرور.

## الموجود

- مدير ينشئ حسابات موظفين؛ لا يوجد تسجيل ذاتي أو اختيار صلاحية المدير من التطبيق.
- خدمة مشتركة لحفظ الحضور والمبيعات، مع صلاحيات يفرضها الخادم: الموظف يرى سجله والمدير يرى آخر 500 تسجيل للجميع.
- رمز جلسة قصير العمر (12 ساعة)، وتخزين محمي في Keychain عند تفعيل البصمة فقط. لا تُحفظ كلمة المرور على الجوال.
- قفل الواجهة عند الانتقال للخلفية. Face ID يفتح الجلسة المحفوظة؛ عند انتهائها يجب إدخال كلمة المرور مجددًا.
- إشعار محلي كل 30 دقيقة أثناء الدوام، يتوقف عند الانصراف. فتح التطبيق مجددًا لا يعيد ضبط تذكير موجود للحساب نفسه.
- تنبيه قرب المحل بعد إذن الموقع، مع تأكيد حضور يدوي. الموقع الافتراضي: 24.6304375, 46.7143125، مركز الرمز 7HP8JPJ7+5P في الديرة بالرياض. نطاق مبدئي 150 مترًا.
- حفظ المبلغ بالهللات كإجمالي للبيع، دون ضربه في الكمية. تحقق من المدخلات ومنع تكرار طلب البيع نفسه.

## التشغيل

1. جهّز خدمة الحسابات وفق [server/README.md](server/README.md)، وأنشئ حساب المدير من أمر `init-admin`. لا يوجد حساب أو كلمة مرور جاهزان.
2. انشر الخدمة على HTTPS مع قرص دائم، ثم أدخل عنوانها في شاشة الدخول. لم تُنشر خدمة ضمن هذا التحديث؛ GitHub لا يشغّل خادم الحسابات تلقائيًا.
3. المشروع يُنشأ من `project.yml` باستخدام XcodeGen. ملف GitHub Actions يفحص اختبارات Python وتجميع iOS للمحاكي عند تعديل ملفات الكود على main، ويمكن تشغيله يدويًا.
4. لتثبيت نسخة على الآيفون يلزم استكمال التوقيع ومعرف التطبيق والأيقونة وتوزيع النسخة المناسبة. TestFlight يحتاج عضوية Apple Developer. نجاح البناء لا ينتج نسخة موقعة قابلة للتثبيت.

## تحقق على آيفون قبل الاعتماد

- ادخل بكلمة المرور، ثم فعّل Face ID من الإعدادات؛ جرّب القفل والعودة، إلغاء البصمة، فشلها، وانتهاء الجلسة.
- اختبر على جهاز مسجّل فيه Face ID فعليًا، واختبر إبطال الجلسة وتغيير البصمات المسجلة. لا يتم إرسال صورة وجه للمدير.
- أنشئ موظفين مختلفين وتحقق من عزل سجلاتهما وتحديث سجل المدير. سلّم بيانات الدخول لكل موظف بشكل خاص.
- اختبر تنبيه الـ30 دقيقة أثناء قفل الشاشة وتوقفه عند الانصراف، ثم اختبر الوصول للمحل ميدانيًا.
- إذن الموقع ووضع التركيز وإعدادات iOS تؤثر في وصول الإشعارات. GPS ليس إثبات وجود دقيقًا عند باب المحل.

## حدود النسخة

تحتاج استضافة فعلية واختبارًا على آيفون؛ لم يُجرَ اختبار Face ID ميدانيًا هنا. تحتاج الشبكة لحفظ الحضور والمبيعات. سجلات النموذج المحلي القديم لا تُرسل للخدمة تلقائيًا. تنبيهات المبيعات تستمر إن نسي الموظف الانصراف، ولم تُضبط ساعات الدوام بعد. تعطيل الحسابات وإعادة تعيين كلمات المرور وتصدير السجلات ليست ضمن هذا الإصدار.
